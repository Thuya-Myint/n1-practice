# JLPT N1 practice roadmap

## Vocabulary — current

- 2,460 strict verified vocabulary entries are integrated into the study app.
- Each entry has two Japanese examples, English translations, and furigana.
- Lesson study, random review, local progress marks, and a multiple-choice meaning exam are available.

### Remaining vocabulary quality pass

- Run a paid-API bilingual audit over all 4,920 Japanese–English example pairs.
- Compare each example against the corrected JMdict sense and flag or revise only translations/usages that fail the audit.
- Keep an audit report and preserve the existing final dataset as the rollback source.

## Next: grammar practice

- Import and structure JLPT N1 grammar points.
- Add concise explanations, formation patterns, contrast notes, and natural examples.
- Build recognition and fill-in-the-blank practice.

## Then: reading practice

- Add graded JLPT N1-style passages with furigana controls.
- Add comprehension questions, timed mode, and review of incorrect answers.
